An executive portfolio and interactive showcase for **Yosef Abire**, an Information Systems & Technology Professional specializing in backend engineering, digital platforms, AI integration, and enterprise systems architecture.

---

## 🌟 Highlights & Features

- **⚡ Executive Summary & Leadership Profile**: Showcasing expertise across systems management, technology strategy, and data-driven solutions.
- **📁 Deep-Dive Case Studies**: Detailed breakdowns of key projects including digital agricultural marketplaces (e.g., AgroGebeya), AI data collection pipelines, and enterprise IT audits.
- **🏗️ Interactive Architecture Lab**: Visualizing system design patterns, database schemas, microservice workflows, and data orchestration.
- **🛠️ Technology Ecosystem**: Comprehensive view of technical skills across backend languages, cloud infrastructure, AI/ML tools, and databases.
- **📄 Interactive Resume Modal**: On-demand interactive view and download options for executive resume versions.
- **📱 Dynamic & Responsive Design**: Crafted with modern dark-mode aesthetic (`#0A0E17`), subtle micro-animations via Framer Motion, and fluid responsive layouts.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- **Node.js**: `v18.x` or higher
- **npm**: `v9.x` or higher

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YosefAbire/portf.git
   cd portf
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.
